# Platform copy specs

Limits are the practical "won't get truncated" sizes, not always the hard maximum. Platforms change these, so if the user cites a different current limit, use theirs.

## Meta (Facebook / Instagram)

| Field | Recommended | Notes |
|---|---|---|
| Primary text | ≤125 chars | Truncated with "See more" after ~125 on feed; hard max is much longer |
| Headline | ≤40 chars | Some placements show ~27 |
| Description | ≤30 chars | Often hidden on mobile; never put key info only here |
| CTA button | fixed list | Shop Now, Learn More, Sign Up, Get Offer, Book Now, Download, Contact Us, Subscribe, Apply Now, Order Now |

Policy watch-outs: no implying personal attributes ("you're in debt"), no unrealistic outcomes, no misleading before/after, restricted categories (finance, health, housing, employment) have extra rules.

## Google Ads

### Responsive Search Ads (RSA)
| Field | Limit | Count |
|---|---|---|
| Headline | 30 chars | 3–15 (aim for 10–15) |
| Description | 90 chars | 2–4 (aim for 4) |
| Display path | 15 chars each | 2 paths |

Include the main keyword in at least 2–3 headlines. Pin sparingly. Pinning reduces combinations.

### Responsive Display Ads
| Field | Limit |
|---|---|
| Short headline | 30 chars (up to 5) |
| Long headline | 90 chars |
| Description | 90 chars (up to 5) |
| Business name | 25 chars |

### Performance Max
Headlines 30 (3–15), long headlines 90 (1–5), descriptions 90 (2–5, one ≤60).

## LinkedIn (Sponsored Content)
| Field | Recommended |
|---|---|
| Intro text | ≤150 chars (truncated after) |
| Headline | ≤70 chars |
| Description | ≤100 chars (shown on few placements) |

Tone: professional, outcome and ROI framing, job-title targeting language.

## TikTok
| Field | Limit |
|---|---|
| Ad text | 12–100 chars |
| Display name | ≤40 chars |

Write it like native captions. Hooks also need a spoken or on-screen version for the first 2 seconds of video, so offer one when you can.

## X (Twitter)
Post text ≤280 (aim ≤100 for ads), headline (website card) ≤70.
