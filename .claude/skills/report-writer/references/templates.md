# Report templates

Pick the one that matches, and drop sections that have nothing to say.

## Weekly status update

```markdown
# Weekly update — [Team/Project] — w/c [date]

**TL;DR:** [one-line outcome]. [key number vs target]. [ask or "no blockers"].

## Highlights
- **[Win]**: impact in numbers

## Metrics
| Metric | This week | Last week | Target | Status |
|---|---|---|---|---|

## In progress
- [Item]: % done / ETA

## Blockers & risks
- 🔴 [Blocker]: what's needed, from whom, by when

## Next week
- [ ] [Action] (owner, date)
```

## Client performance report

```markdown
# [Client] — [Channel] performance — [period]

**TL;DR:** [result vs goal in one line]. [what we're doing next].

## Results vs goals
| KPI | Goal | Actual | Δ vs last period | Status |
|---|---|---|---|---|

## What worked
- **[Thing]**: evidence

## What didn't, and what we're doing about it
- **[Thing]**: cause → fix

## Next period plan
1. [Action]: expected impact

## Appendix
Breakdown tables by campaign / creative / audience.
```

## Campaign recap / post-mortem

```markdown
# [Campaign] recap

**TL;DR:** [outcome vs objective]. [biggest learning].

## Objective & setup
Goal, budget, dates, channels, audiences.

## Results
| KPI | Target | Actual |

## What worked / what didn't
| Worked | Didn't |
|---|---|

## Learnings → next time
1. [Learning] → [specific change]
```

## Executive summary

```markdown
# [Topic]

**Decision needed:** [yes/no or option choice] by [date].

**Context (2–3 lines):** …

**Recommendation:** … because [1–2 reasons with numbers].

**Options considered:** A (rec), B, C with a one-line trade-off each.

**Risk if we don't act:** …
```

## One-pager / proposal

```markdown
# [Proposal title]

**Ask:** [what you want approved, budget/time].

## Problem
Evidence-backed, 2–4 lines.

## Proposal
What, how, who.

## Expected impact
Numbers, with assumptions stated.

## Cost & timeline
| Item | Cost | Date |

## Risks & mitigations
```
